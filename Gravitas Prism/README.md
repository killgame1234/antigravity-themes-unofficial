# 🌌 Gravitas Prism

> *An ambient cinematic media engine and glassmorphic workstation theme for Google Antigravity.*

Gravitas Prism seamlessly refracts live video and audio streams into dynamic, breathing ambient lighting across your Antigravity IDE workspace.

---

## ✨ Core Capabilities

- **Refractive Ambient Engine:** Real-time canvas sampling extracts live video hues (`--ytg-r`, `--ytg-g`, `--ytg-b`) to gently illuminate card outlines and UI borders without harsh glows.
- **Three Viewing Modes:**
  - 🖼️ **Background:** Full ambient canvas behind your workspace.
  - 🌓 **Split Side-Panel:** Resizable side-by-side cinema pane with a draggable vertical sash, live chat width adjustment, and side swap (Left/Right).
  - 🪟 **Float PiP:** Draggable and resizable picture-in-picture viewport.
- **Floating Capsule Pill:** Minimize the full panel into an ultra-compact pill with inline Play/Pause, Next Track, Mute, and Layout cycle toggles.
- **Integrated YouTube Search & Queue:** Search directly from the controller (`/search`), load playlists (`/playlist`), and queue tracks with automatic progression.
- **Pure Transparent Left Sidebar:** Native file tree and workspace navigation with zero occlusion.

---

## ⌨️ Global Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Alt + Shift + P` | Play / Pause |
| `Alt + Shift + M` | Mute / Unmute |
| `Alt + Shift + N` | Next Track |
| `Alt + Shift + B` | Previous Track |
| `Alt + Shift + S` | Cycle Layout (Background ➔ Split ➔ Float) |
| `Alt + Shift + H` | Toggle Controller Visibility |
